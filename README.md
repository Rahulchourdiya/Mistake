📁 Objective:

The goal of this project is to analyze the Netflix dataset to uncover trends in content types, user preferences, popular genres, release trends over the years, and insights into Netflix’s content strategy.

📚 Dataset:

Source: Kaggle Netflix Dataset

Features: Title, Type (Movie/TV Show), Director, Cast, Country, Date Added, Release Year, Rating, Duration, Genre (listed_in), and Description.


🔧 Technologies Used:

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook


📈 Key Analysis Performed:

1. Data Cleaning & Preprocessing

Removed null and duplicate values

Converted date fields to datetime format

Extracted features like year, month, and duration



2. Exploratory Data Analysis (EDA)

Number of movies vs TV shows

Top countries producing Netflix content

Most frequent genres and their trends over the years

Rating distribution (TV-MA, PG, R, etc.)

Year-wise content addition trend



3. Visualization Insights

Bar plots, pie charts, heatmaps, and word clouds to represent data visually

Most frequent directors and actors

Monthly release pattern of content



4. User Behavior Insights

Analysis of popular content types per region

Duration pattern between movies and TV shows

Trends in content rating with respect to genres




📌 Conclusion:

This analysis gives a comprehensive view of Netflix’s content strategy, helping understand what types of shows/movies are more frequent, which regions dominate content production, and how Netflix is evolving year by year in terms of content types and genres.
